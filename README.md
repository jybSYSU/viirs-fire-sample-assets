# VIIRS Fire-Detection Sample Asset Gallery

A curated gallery of **human-reviewed** sample figures for VIIRS 375 m fire
detection research (Guangzhou Meteorological Satellite Ground Station).
Only a small sampled subset of figures is published here; the full asset
library is not yet public.

## Contents

| Path | Description |
|---|---|
| `index.html` | Gallery homepage (auto-published via GitHub Pages) |
| `images/<category>/` | Sampled review figures (PNG, 12–16 per category, 208 total) |
| `data/sample_manifest.json` | Sampling manifest (category counts, fixed seed 20260923) |

## Categories

Grouped into fire and non-fire classes:

- **Fire**: confirmed fire (daytime / nighttime), large-fire events
- **Non-fire**: industrial heat sources, photovoltaic plants, open burning
  (incl. volcano), high-temperature surfaces, urban, cropland (non-fire),
  water bodies, heated water bodies, clean background
